# tengmesk.com

Personal site of Tengo Meskhi, v2.0: a light, editorial, bilingual (English + ქართული) professional page and an About page. Built with [Astro](https://astro.build) as plain static output, vanilla CSS with design tokens, and a few kilobytes of hand-written JavaScript.

The plan that governs the site is [`docs/redesign/SITE-PLAN.md`](docs/redesign/SITE-PLAN.md); the build journal is in [`docs/journey/`](docs/journey/).

## Run

```sh
npm install
npm run dev            # http://localhost:4321
npm run build          # static site in dist/
npm run preview        # serve dist/
npm run build:preview  # dist-preview/ with relative URLs (works from file:// or any subfolder)
npm run check          # astro check (types + templates)
npm run og             # regenerate public/og/*.png (needs Playwright)
npm run shots          # screenshots + acceptance checks from dist/ (needs Playwright)
npm run weights        # first-view page weight vs the plan's budgets (needs Playwright)
```

Node 22 or newer.

## Where things live

| Path | What |
|---|---|
| `assets/media.yaml` | **Content source of truth**: person, socials, roles, ventures, recognition, talks, teaching, press, interviews, photos. |
| `assets/photos/`, `assets/press/` | Original images. Photos are picked up by `file` path from `media.yaml` and optimised at build time (AVIF + WebP). |
| `src/i18n/en.ts`, `src/i18n/ka.ts` | Every copy string, keyed by the ids in SITE-PLAN §4. `ka.ts` must have the same keys as `en.ts` (TypeScript checks this). |
| `src/content/media.ts` | Typed, validated loader for `media.yaml`, plus the ordering rules the plan specifies. |
| `src/views/Home.astro`, `src/views/About.astro` | The two pages, rendered once per language from `src/pages/`. |
| `src/styles/global.css` | Design tokens and all component styles. `src/styles/fonts.css` self-hosts the fonts from the `@fontsource` packages. |
| `src/lib/contours-*.ts`, `src/scripts/contour-field.ts` | The hero contour field: build-time SVG fallback and the canvas island. |
| `public/og/` | Open Graph images, generated by `npm run og` and committed. |

## Editing content

Edit `assets/media.yaml` and rebuild. Keep ids stable. Unknown values are the literal `tbc`; the site never renders that string, it omits the field instead (no date column until roles have a `period`, no "Visit" link until a venture has a `url`, no email button until `person.email` is set, and so on). When a venture gets a `summary`, the Now section switches from a ruled list to cards automatically.

Copy that is not data (headings, paragraphs, labels) lives in `src/i18n/`. Georgian strings are a draft awaiting native review.

## Deploy

The build is host-agnostic: `dist/` is plain static files. `site` and `base` come from the environment:

- `SITE_URL` — origin used for canonicals, OG and sitemap (default `https://tengmesk.com`)
- `BASE_PATH` — path prefix for a project page (default `/`)

`.github/workflows/deploy.yml` builds and publishes to GitHub Pages. With no repository variable set it targets the project-page staging URL (`https://tengmesk.github.io/tengmesk.com/`); set the repository variable `SITE_URL` to a custom domain to build for the root. No `CNAME` is committed yet; the domain cutover is a later step.

The long-term host is Cloudflare (Workers static assets / Pages), for a contact form, bot protection and crawler management. The same `dist/` deploys there unchanged; `public/_headers` already carries security headers and immutable caching for `/_astro/*`, which Cloudflare honours and other hosts ignore.

# Page override: home (tengmesk.com homepage)

> Overrides `../MASTER.md`. Generated by the ui-ux-pro-max `--design-system --page home` run, then
> edited by hand where the content brief (BRIEF.md) wins over the database match.

## Why the overrides

The `--design-system` run matched **Luxury/Premium Brand** (black + gold) and the **Liquid Glass** style.
BRIEF §7 mandates a *forest-y palette: deep rich green, brown, nice off-whites* and a "sharp, credible,
builder" first impression, so the palette and style are replaced here. Everything else from MASTER
(pattern, spacing density, motion tier, anti-patterns, checklist) is kept.

## Pattern (kept, merged)

**Scroll-Triggered Storytelling** (MASTER) merged with **Trust & Authority + Conversion**
(`--domain landing` result 4: Hero > Proof (logos, stats) > Solution > Clear CTA) and
**Hero + Testimonials + CTA** (result 1: social proof before CTA).

Section order:
1. Intro hook: hero (positioning, portrait, city tracker, Book a call) + stat row
2. Proof strip: employer/alma-mater logos
3. Chapter 1 (journey): "Every side of the table" career arc
4. Chapter 2 (results): Conceptdigital numbers + client logos
5. Chapter 3 (solution): where he can help + mini CTA
6. Point of view: opinions band (dark green)
7. Testimonials (Clutch 5.0 / 14 reviews)
8. Speaking & teaching (photos + list) + press
9. Off the clock (character photos)
10. Health teaser (one line)
11. Climax CTA: Book a call / LinkedIn / email + newsletter UI
12. Footer

## Style (override)

**Editorial Minimal + organic motif** (`--domain style`: Minimalism & Swiss Style, adapted).
Generous whitespace, grid-based, type-led hierarchy, one accent only, contour/terrain SVG motif
generated in code (BRIEF §7 says contour motifs still fit). No glass, no blur-as-decoration.
Light mode by default; dark green bands for rhythm. Radius scale: 4 / 12 / 999px.

## Typography (override)

- Display: **Fraunces** (variable; opsz 9–144, SOFT axis) – verified in `--domain google-fonts`.
  Self-hosted via `@fontsource-variable/fraunces`. Used at opsz 144 / SOFT 50 for headlines.
- Body/UI: **Instrument Sans** (variable wght 400–700) – verified in `--domain google-fonts`.
  Self-hosted via `@fontsource-variable/instrument-sans`.
- Scale (fluid): display 48→104px, h2 32→56px, h3 22→28px, body 17→18px, label 12–13px uppercase tracked.
- Line-height: 1.0 display, 1.1 h2, 1.55 body. Max measure 62ch.

## Spacing

Density 3/10 kept: 4 / 8 / 24 / 32 / 48 / 64 / 96 (+ 128 hero).

## Motion (tier: Standard, from MASTER + `--domain gsap` subtle scroll reveal)

- Scroll reveal: opacity 0→1, y 12px, 350–450ms, power1.out, once (IntersectionObserver; no GSAP
  needed for this amount of motion, keeps bundle at 0 deps).
- Stagger grids: 40–60ms per item.
- Hover: 200ms; press: scale 0.98.
- Logo strip marquee: pauses on hover/focus; static under reduced motion.
- `prefers-reduced-motion: reduce` → all reveals render final state immediately, marquee static, no transforms.
- Content is never invisible without JS (reveal class only applied when JS runs).

## City tracker component

"Now: Miami" pill in the nav and hero. Implemented as a `<button aria-expanded>` that toggles a
`Coming up: …` popover; also opens on hover and focus-within (CSS), so mouse, keyboard (Enter/Space/Esc)
and touch (tap toggles) all work. Data injected at build time from `data/whereabouts.yaml`.
